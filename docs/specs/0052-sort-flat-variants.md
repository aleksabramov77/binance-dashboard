# 0052 · Сортировка главнее групп вариантов в /experiments

- **Тип:** feature
- **Статус:** done
- **Раздел PRD:** §3.4 «Авто-бот» → «Лаборатория экспериментов» (варианты — [spec 0046](0046-lab-history-variants.md))
- **Дата:** 2026-10-16

## Цель
В `/experiments` A/B-варианты стоят под своим контрольным экспериментом (spec 0046, AC8), поэтому при сортировке по
PnL, win rate и другим колонкам порядок не монотонный: сортируются только группы, а варианты всегда идут сразу под
контрольным. Выбранная сортировка должна ставить каждую строку на её место, а связь «вариант — контрольный» — оставаться
видной.

## Решение пользователя (2026-10-16)
«Нужно придумать способ, чтобы сортировка по любой колонке сортировала независимо от того, … является АБ-тестом какого-то
эксперимента или нет… если выбрана какая-то сортировка, то она имеет больший приоритет, чем группировка». Скриншот:
сортировка PnL ↓ — после +0,02 $ идут −5,96 $ и −12,88 $, затем снова +35,85 $.

## Сценарии
1. Пользователь открывает `/experiments` без выбранной сортировки (по умолчанию — колонка «Эксперимент») → видит группы,
   как сейчас: F96, под ним «↳ F97 · вариант A · …» и «↳ PS99 · вариант B · …», шеврон у F96 сворачивает их.
2. В меню заголовка «PnL» выбирает «По убыванию» → таблица плоская: все строки, включая варианты, строго по PnL от
   большего к меньшему. У F97 рядом с кодом — метка «вариант A от F96», вторая строка — «вариант A · что изменено»;
   шевронов и отступов нет; варианты, свёрнутые раньше шевроном, тоже видны.
3. Над таблицей — строка «Сортировка по «PnL»: варианты A/B стоят на своих местах» и кнопка «Сгруппировать варианты» →
   сортировка сбрасывается к умолчанию, возвращаются группы и прежняя свёрнутость.
4. Сортировка по колонке «Эксперимент» (по возрастанию или убыванию) — группы, как в сценарии 1.

## Критерии приёмки
- [x] AC1. **Групповой вид.** Без сохранённой сортировки и при сортировке по «Эксперимент» (↑ или ↓) таблица показывает
  группы, как в spec 0046 AC8: контрольный, под ним варианты с отступом, «↳» и шевроном у контрольного.
- [x] AC2. **Плоский вид.** При сортировке по любой колонке, кроме «Эксперимент» (Вкл., AG, Сделки, Win rate, PnL,
  Profit factor, Max DD, Equity, Реал, все демо-колонки), строки идут строго по значению колонки: варианты не прижаты к
  контрольному; пустые значения — в конце, при равенстве — по id, как сейчас.
- [x] AC3. **Чей вариант — видно.** В плоском виде у строки варианта рядом с кодом — метка «вариант <буква> от <id
  контрольного>» (id — ссылка на страницу контрольного), вторая строка — «вариант <буква> · <что изменено>»; отступа,
  «↳» и шеврона нет. Буква та же, что в групповом виде (по порядку id среди вариантов контрольного во всём списке).
- [x] AC4. **Свёрнутые не прячутся.** В плоском виде видны все строки, в том числе варианты, свёрнутые шевроном в
  групповом виде; сохранённая свёрнутость (localStorage) не теряется и снова действует в групповом виде.
- [x] AC5. **Возврат к группам.** В плоском виде над таблицей — строка «Сортировка по «<колонка>»: варианты A/B стоят на
  своих местах» и кнопка «Сгруппировать варианты»; кнопка сбрасывает сортировку к умолчанию, таблица возвращается к
  группам. В групповом виде строки и кнопки нет. На ширине телефона строка и кнопка переносятся, без горизонтального
  скролла страницы.
- [x] AC6. **Фильтры как раньше.** Фильтр группы активов и выбор эпохи работают в обоих видах; вариант, контрольного
  которого нет в списке (фильтр AG), в обоих видах — обычной строкой с меткой «вариант <буква> от <id>».
- [x] AC7. **Тесты.** Vitest на раскладку строк: групповой вид — только при сортировке по id; плоский — монотонный
  порядок по колонке для смешанного списка контрольных и вариантов, метка варианта (буква, id контрольного), свёрнутые
  контрольные не прячут варианты в плоском виде.

## Вне scope
- Отдельный переключатель «группировать / не группировать» независимо от сортировки.
- Группы вариантов в других таблицах (`/settings`, `/stats`, страница эксперимента).
- Правила вариантов из spec 0046: буквы, «что изменено», сравнение на странице эксперимента.

## Технические заметки
- `src/pages/experiments/lib/sortExperiments.ts`: `arrangeVariants` получает режим (`grouped`); в плоском режиме
  строки идут в порядке отсортированного списка, у варианта заполнены id контрольного и буква, но он не вложен
  (отдельный признак вложенности для ячейки — отступ, «↳»).
- `src/pages/experiments/ui/ExperimentsPage.tsx`: групповой вид — когда колонка сортировки `id`; фильтр свёрнутых —
  только в групповом виде; строка-подсказка и кнопка «Сгруппировать варианты» сбрасывают сортировку таблицы
  (`useTableSort` → `onReset`). Название колонки в подсказке — из того же списка колонок, что и заголовки.
- Spec 0046, AC8 — пометка, что правило сортировки изменено задачей 0052.
- Публичный репозиторий: в тестах, spec и PR — только вымышленные id (F96–F98, PS99).
