# 006 · Вход только через GitHub

- **Тип:** feature (задача 4 эпика [spec 003](003-experiments-lab.md) «Лаборатория экспериментов»)
- **Статус:** done
- **Раздел PRD:** §4 «Ключи и окружение»
- **Дата:** 2026-10-10

## Цель
Приложение уезжает на облачную VM. Посторонние не должны открыть дашборд, потратить токены
OpenRouter или нажать кнопки сделок и сброса. Войти может только владелец через свой GitHub.

## Решения пользователя (2026-10-10)
Вход через GitHub (Auth.js), allowlist `aleksabramov77`; паролей нет.

## Критерии приёмки
- [x] AC1. Production с настройками: страница без сессии → редирект на `/login?callbackUrl=…`; API → 401
  `{"error":"Нужен вход"}`; «Войти через GitHub» ведёт на GitHub OAuth.
- [x] AC2. Чужой GitHub-логин не входит: `/login?error=AccessDenied` объясняет причину; в журнале `auth.denied`.
- [x] AC3. Production без `AUTH_*` (или с частью) — всё закрыто, 503 с перечнем переменных (fail-closed).
- [x] AC4. Локально без `AUTH_SECRET` защита выключена: страницы открыты, меню пользователя скрыто.
- [x] AC5. `POST /api/cron/tick`: без секрета или с неверным → 401, с верным `Bearer $CRON_SECRET` → 204
  (заготовка; тик движка подключат задачи 1d/2b). В production без `CRON_SECRET` → 503.
- [x] AC6. В хедере — аватар и логин GitHub и кнопка «Выйти».

## Технические заметки
- `proxy.ts`, `src/app/server/auth.ts`, `shared/lib/auth/*` (чистые правила + тесты), `features/auth`,
  `pages/login`, `app/api/auth/[...nextauth]`, `app/api/cron/tick`.
- `next-auth@5.0.0-beta.32` (peer: Next 16). `trustHost: true` — сервер за своим Caddy.
