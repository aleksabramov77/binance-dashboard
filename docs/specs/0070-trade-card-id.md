# 0070 · Карточка сделки: идентификатор, «без тейка», сумма риска

- **Тип:** feature (доработка 0068)
- **Статус:** approved
- **Раздел PRD:** §3.6 «Сообщения о сделках»; очередь задач 28.2
- **Дата:** 2026-10-18

## Цель
Первая настоящая карточка (F16, short ICNT) выглядела странно: строки TP не было, стоп −23,9 %, и по карточке
нельзя быстро найти сделку в базе. F16 — пробой канала Дончиана без тейка: стоп 2 ATR, дальше скользящий стоп
2 ATR, выход вслед за paper-сделкой. Карточка должна это объяснять и давать идентификатор для разбора (запрос
пользователя 2026-10-18).

## Критерии приёмки
- [ ] AC1. **Идентификатор.** Последней строкой карточки (после 🏦 Баланс, без пустой строки) — `🆔 <trade_id>`; в
  Telegram id моноширинный (`<code>`, нажатие копирует), в журнале — простой текст. Во всех статусах и в пробной
  цепочке.
- [ ] AC2. **Без тейка.** Если тейка нет, на месте TP в лесенке — строка без цены: при скользящем стопе эксперимента —
  «🟩 без тейка — скользящий стоп N ATR», иначе «🟩 без тейка — выход по стратегии». Порядок лесенки прежний (у long
  сверху, у short снизу). Данные о выходе — из конфига эксперимента (`exit.trailAtr`, `exit.takeProfit`); конфиг не
  прочитан — «выход по стратегии».
- [ ] AC3. **Сумма риска и цели.** У 🟥 после процента — сумма возможного убытка, у 🟩 — возможной прибыли, по объёму
  и цене входа (без комиссий): «🟥 0,212058  −23,9 %  −$2,37». Объёма или цены входа нет — только процент.
- [ ] AC4. Вид версии 3 (spec 0068) в остальном не меняется; простой текст и HTML, кнопки, замена карточки — как были.
- [ ] AC5. Unit-тесты: id во всех статусах (HTML — в `<code>`, экранирован), без тейка с трейлингом и без, суммы у
  long и short. Реальных отправок из тестов нет.

## Вне scope
- Перенос реального стопа на бирже вслед за трейлингом paper-сделки — в сторож 28.4 (решение пользователя 2026-10-18).
