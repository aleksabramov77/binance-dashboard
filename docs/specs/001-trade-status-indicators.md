# 001 · Индикаторы статуса и ссылки на график в «Демо-сделках»

- **Тип:** feature
- **Статус:** review
- **Раздел PRD:** §3.3 «Сигналы и сделки» → «Статусы сделок и ссылки на график»
- **Дата:** 2026-10-10

## Цель
В блоке «Демо-сделки» сразу видно, чем кончилась каждая сделка (TP, SL, ручное закрытие в плюс/минус)
и что с открытыми позициями (без стопа, стоп подтянут в прибыль). Из строки одним кликом открывается
график пары на Binance Demo.

## Сценарии
1. Пользователь открывает `/signals` → в «Демо-сделках» у каждой строки (ордера) индикатор статуса сделки,
   к которой относится ордер; наведение показывает подсказку.
2. Клик по паре (`BAT-USDT`) → в новой вкладке страница пары на demo.binance.com (Spot или Futures).
3. Под таблицей — легенда индикаторов.

## Решения пользователя (2026-10-10)
- Строка таблицы — **ордер** (вход и выход — разные строки). У всех ордеров одной сделки один индикатор —
  статус сделки.
- Ссылка на график — страница пары на **Binance Demo**, новая вкладка.
- «Пошла к TP со скользящим SL» — **только индикатор**: позиция открыта, стоп на бирже в зоне
  безубытка/прибыли или стоит trailing-ордер. Само приложение стоп не двигает.
- Открытая сделка — пустой кружок с контрастной окантовкой.

## Статусы сделки
| Статус | Когда | Индикатор |
|---|---|---|
| Открыта | позиция есть, стоп в зоне убытка | пустой круг, контрастная окантовка |
| Открыта, стоп подтянут | позиция есть, SL в безубытке/прибыли (лонг: SL ≥ входа; шорт: SL ≤ входа) или trailing-стоп | пустой круг, зелёная окантовка |
| Открыта без стопа | позиция есть, SL/trailing на бирже нет | пустой круг, жёлтая окантовка |
| Закрыта по TP | выход — `TAKE_PROFIT_MARKET` (futures) / `LIMIT_MAKER` из OCO (spot) | зелёный круг |
| Закрыта по стопу в плюс | выход — SL/trailing, PnL сделки > 0 | зелёный круг с кольцом |
| Закрыта по SL | выход — SL, PnL ≤ 0 | красный круг |
| Закрыта вручную в профит | выход — обычный ордер, PnL > 0 | зелёный квадрат |
| Закрыта вручную в лосс | выход — обычный ордер, PnL ≤ 0 | красный квадрат |
| Ликвидация | выход — ордер ликвидации/ADL | красный ромб |
| Статус неизвестен | позиции нет, а выхода в истории нет (сброс демо-счёта), или данные для статуса не загрузились | серый пунктирный круг |

## Критерии приёмки
- [x] AC1. Таблица «Демо-сделок» сохраняет колонки (время | сторона | пара | рынок | объём/цена/PnL | комиссия),
  перед временем — колонка индикатора.
- [x] AC2. Индикаторы по таблице статусов; вход и выход одной сделки — одинаковый индикатор. На демо-счёте
  2026-10-10: шорты BAT-USDT (00:03→01:42) и MAGIC-USDT (20:56→21:51, 00:03→00:10) — красные круги;
  открытые шорты KAIA/ATOM/BAT/MAGIC/ZK/US со стопом в зоне убытка — пустые круги с контрастной окантовкой;
  ETH-USDT spot (монеты нет, выхода нет) — серый пунктир.
- [x] AC3. Наведение на индикатор показывает статус; у открытых futures — текущий SL и нереализованный PnL
  («Открыта, стоп стоит · вход · SL 0,1402 · сейчас PnL -0,30 $»).
- [x] AC4. Пара — ссылка в новой вкладке: Futures → `https://demo.binance.com/en/futures/BATUSDT`,
  Spot → `https://demo.binance.com/en/trade/ETH_USDT?type=spot`.
- [x] AC5. Под таблицей — легенда всех индикаторов.
- [x] AC6. PnL у выходов: futures — из Binance, spot — от средней цены входа. У входов PnL нет.
- [x] AC7. На узком экране таблица скроллится внутри карточки (Tester: 390×844, таблица 788 px в контейнере 308 px).
- [x] AC8. Не загрузились данные для статусов по символу → у его строк «статус неизвестен», блок не падает
  (юнит-тест `markTrades(…, null)`).
