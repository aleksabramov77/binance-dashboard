# 0038 · Остатки Paper | Demo | Real по группам в шапке и сбросы по группе («эра группы»)

- **Тип:** feature (задача B из плана [spec 0016](0016-glossary-ag-demo-columns.md); D часть 1 — [0023](0023-coinm-asset-group.md))
- **Статус:** approved
- **Раздел PRD:** §3.4 Авто-бот → «Счета и группы активов»; «Очередь задач», строка 10
- **Дата:** 2026-10-16

## Цель
В шапке видна только Paper-лаборатория. Demo-балансы есть лишь на `/settings`, и то только USDT по Spot и USDⓈ-M.
Real в шапке нет, хотя read-only ключ уже есть. Сбросы бывают только «всё». Задача показывает в шапке все три счёта
по каждой группе активов (`SPOT`, `FT:USDM`, `FT:COINM`) и даёт сбросить одну группу, не трогая остальные.

## Решения пользователя (2026-10-16)
1. **Шапка: чипы и поповер.** Три чипа групп `SPOT` / `FT:USDM` / `FT:COINM`.
   - В чипе крупно Paper (equity и изменение %), мелко D (Demo) и R (Real).
   - Клик открывает поповер с таблицей 3×3 и ссылкой «Сбросы →» на `/settings#groups`.
   - На экране уже `sm` вместо чипов одна кнопка «Счета» с итогом Paper, таблица — в том же поповере.
2. **Real — живые остатки** через существующий read-only ключ: `fetchWalletBalances`
   (`/sapi/v1/asset/wallet/balance`, quoteAsset USDT).
   - Кошельки «Spot», «USDⓈ-M Futures», «COIN-M Futures» раскладываются по группам.
   - Нет ключа или ошибка → «—» с подсказкой. Торговли с Real нет.
3. **Demo — equity счёта в $**, как на demo.binance.com.
   - Spot: все балансы (free + locked) × цена в $.
   - USDⓈ-M: (walletBalance + unrealizedProfit) по активам × цена.
   - COIN-M: `demo-dapi.binance.com/dapi/v1/balance`, (balance + crossUnPnl) по активам × цена.
   - Читается только баланс; демо-зеркала COIN-M в этой задаче нет.
4. **«Эра группы» — сброс экспериментов группы, без новой эпохи `runs`.**
   - **Paper группы.** Одна транзакция под блокировкой тика для всех экспериментов группы (включая выключенные):
     - закрыть открытые paper-сделки по последней цене (`manual`; без цены — по цене входа, `resetWithoutPrice`);
     - `reset_at = now()`;
     - `initial_budget = next_budget`;
     - отметить текущие свечи обработанными (`engine_state.bars`).
   - **Demo группы.** Закрыть по рынку демо-позиции зеркал экспериментов группы и поставить `demo_reset_at` у этих
     экспериментов. Для COIN-M кнопка неактивна: демо-зеркала COIN-M нет.
   - Без миграции; движок и Edge Function не меняются.
5. **Согласование с лабораторией** (уточнение пользователя через сессию header-three-account-groups).
   - Эпоха 2 стартует текущими «Сбросить все Paper» (`resetRun`) и «Сбросить всё Demo» на `/settings`.
   - Задача разрабатывается параллельно. Вливается либо после старта эпохи 2 (сообщит сессия lab-experiment-review),
     либо так, что обе кнопки остаются на месте и ведут себя как раньше; это фиксируют регрессионные тесты (AC9).
   - Перед мержем — вопрос сессии lab-experiment-review о статусе эпохи 2 и решение пользователя.

## Сценарии
1. Пользователь на любой странице смотрит в шапку → видит по каждой группе Paper (equity, %), Demo и Real в $.
2. Клик по чипу → поповер: таблица групп × счетов с изменением Paper от старта учёта и ссылкой «Сбросы →».
3. На телефоне (375 px) вместо трёх чипов — кнопка «Счета»; по нажатию тот же поповер, страница не скроллится вбок.
4. На `/settings` в карточке «Сбросы по группам» пользователь нажимает «Сбросить Paper» у `FT:USDM` → диалог честно
   говорит, сколько сделок закроется, с каким бюджетом начнётся учёт и что не меняется → после подтверждения меняется
   только чип `FT:USDM`, номер эпохи тот же.
5. Там же «Сбросить Demo» у `SPOT` → диалог: сколько демо-позиций закроется по рынку, демо-статистика группы
   начнётся заново, баланс на Binance не меняется (ссылка на demo.binance.com).

## Критерии приёмки
- [ ] AC1. В шапке на ширине ≥ sm три чипа групп.
  - В каждом Paper (equity, изменение %), Demo и Real в $.
  - Подсказка `title` расшифровывает счета.
- [ ] AC2. Клик по чипу или по кнопке «Счета» (< sm) открывает поповер с таблицей.
  - Таблица в `TableFrame`: строки — AG, колонки — Paper (equity, Δ $ и %) | Demo | Real.
  - Внизу ссылка «Сбросы →» на `/settings#groups`. На 375 px нет горизонтального скролла страницы.
- [ ] AC3. Demo-equity по трём группам считается по правилам решения 3 и совпадает с суммой активов демо-счёта
  (проверка на локальном сервере с демо-ключом).
  - Нет демо-ключа, ошибка или пауза после 429/418 → «—» с причиной в подсказке; Paper при этом показывается.
- [ ] AC4. Real по трём группам берётся из wallet balance; нет ключа или ошибка → «—» с подсказкой.
- [ ] AC5. Новые подписанные запросы идут через `signedRequest` и соблюдают паузу после 429/418.
  - Ответы Demo и Real кэшируются на сервере на 60 с, поэтому шапка (refetch 30 с) делает не больше
    1 запроса в минуту к каждому хосту.
- [ ] AC6. На `/settings` карточка «Сбросы по группам» (`id="groups"`, таблица в `TableFrame`). По каждой группе:
  - число экспериментов, открытых paper-сделок и открытых демо-позиций;
  - кнопки «Сбросить Paper» и «Сбросить Demo» (через `ConfirmAction`).
- [ ] AC7. Диалог «Сбросить Paper» группы честно говорит, что произойдёт.
  - Сколько открытых сделок закроется по последней цене; учёт N экспериментов начнётся с бюджета $X.
  - Эпоха №K и другие группы не меняются; демо-позиции этих сделок закроет зеркало в течение минуты.
  - После подтверждения Paper этой группы в шапке = N × $X, остальные группы без изменений.
- [ ] AC8. Диалог «Сбросить Demo» группы говорит, сколько демо-позиций закроется по рынку и что демо-статистика
  экспериментов группы начнётся заново.
  - Баланс на Binance не меняется: ссылка на demo.binance.com, где сбрасывается весь счёт, а не группа.
  - Для COIN-M кнопка неактивна с подсказкой «Демо-зеркало COIN-M — позже».
- [ ] AC9. «Сбросить все Paper» и «Сбросить всё Demo» на месте и ведут себя как раньше.
  - Регрессионные тесты: `resetRun` — новая эпоха и защита `fromRunId`; `resetDemo(null)` — все эксперименты.
- [ ] AC10. Глоссарий `docs/ai/glossary.md` (термин «Сброс» — добавлен сброс группы) и `/help` обновлены (`pnpm glossary`).

## Вне scope
- Демо-зеркало COIN-M (очередь задач, строка 11).
- Статистика `/stats` по счетам Paper / Demo / Real (задача C, строка 12).
- Торговля с Real-счёта.
- Эпохи `runs` по группам (колонка `market` в `runs`).
- Сброс баланса демо-счёта на Binance: API-метода нет, только кнопка на demo.binance.com.

## Технические заметки
- **shared/api/binance**
  - `demoTrading.ts`: `fetchDemoEquity(creds)` → `{ spot, usdm, coinm }` в $ (по группе — число или ошибка);
    хост `demo-dapi.binance.com` в `DEMO_URL`; zod-схемы ответов `/api/v3/account`, `/fapi/v3/balance`
    (или `/fapi/v3/account`), `/dapi/v1/balance`; экспорт через `demo.server.ts`.
  - Оценка в $ — `fetchTickerPrices` и `resolveUsdPrice` (как в `features/load-portfolio`).
  - Real: `fetchWalletBalances` (`accountClient.ts`) и чистая функция раскладки кошельков по группам.
- **entities/account-balance** (новый слайс)
  - `model`: тип балансов Demo и Real по группам.
  - `api`: `useAccountBalances` (TanStack Query, ключ `["accounts","balances"]`, refetch 30 с).
- **Сервер**: `src/app/server/accountBalances.ts` (Demo и Real параллельно, кэш 60 с в `globalThis`, как цены в
  `experimentBudgets.ts`), маршрут `app/api/accounts/balances/route.ts` с `withLogging`.
- **widgets/account-balances** (новый): чипы и поповер; использует `useExperimentBudgets` и `useAccountBalances`.
  `AppHeader` рендерит его вместо `MarketBudgets`.
- **Сброс по группе**
  - `settingsDb.ts`: `resetGroupRun` по образцу `resetExperimentRun`.
  - `experimentSettings.ts`: `resetGroupCapital(market)` по образцу `resetExperimentCapital`
    (`withTickLock` → `planReset` → `withEngineTickLock`).
  - `demoMirror.ts`: `resetDemo` получает фильтр группы; вызов `resetDemo(null)` не меняется.
  - Маршрут `POST /api/experiments/reset/group { market, account: "paper" | "demo" }` с zod.
  - Мутации инвалидируют `["experiments"]` и `["accounts"]`.
  - UI — `src/pages/settings/ui/GroupResetsCard.tsx`.
- **Риски**
  - Демо-счёт общий с продом: на локальном сервере сброс Demo группы не нажимать — только тесты и текст диалога.
  - Сброс группы меняет `initial_budget` её экспериментов: статистика старой эпохи по ним пересчитается от нового
    бюджета (тот же открытый вопрос PRD §6, что и у общего сброса).
  - Шапка опрашивается раз в 30 с на каждой странице: без серверного кэша новые подписанные запросы рискуют баном
    IP (см. [spec 0014](0014-binance-ip-ban.md)).
