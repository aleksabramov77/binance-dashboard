# Бэклог гипотез

Все карточки гипотез лаборатории с сквозными номерами `H<n>`. Карточка целиком — в `runs/<дата>/ideas.md`
прогона, здесь — строка с статусом и критериями, по которым следующий прогон проверяет заведённый эксперимент.
Правила и статусы — `.claude/skills/trading-lab/references/outputs.md` → «hypotheses.md». Эксперименты
исходного каталога (S01–S20, F01–F20) карточек не имеют: к ним применяются пороги по умолчанию из
`references/metrics.md`.

Статусы: `backlog` (pursue, не заведена) · `pursue` (заводится или идёт — id в «Эксперимент») · `discard` ·
`killed` / `mirrored` / `done` (итог эксперимента по следующему разбору).

| H | Дата | Гипотеза (коротко) | Основание | Статус | Эксперимент | Kill | Success | Прогон |
|---|---|---|---|---|---|---|---|---|

Карточек пока нет — первые появятся после первого прогона `/flow lab`.
