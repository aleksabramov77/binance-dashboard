# Бэклог гипотез

Все карточки гипотез лаборатории с сквозными номерами `H<n>` — pursue, revise и discard: так номера не повторяются, а
отклонённое не предлагается заново без нового основания. Карточка целиком — в `runs/<дата>-<NNNN>/ideas.md` прогона,
здесь — строка со статусом и критериями, по которым следующий прогон проверяет заведённый эксперимент.
Правила и статусы — `.claude/skills/trading-lab/references/outputs.md` → «hypotheses.md». Эксперименты исходного
каталога (S01–S20, F01–F20) карточек не имеют: к ним применяются пороги по умолчанию из `references/metrics.md`.

Статусы: `backlog` (pursue, не заведена) · `pursue` (заводится или идёт — id в «Эксперимент») · `revise` · `discard` ·
`killed` / `mirrored` / `done` (итог эксперимента по следующему разбору).

| H | Дата | Гипотеза (коротко) | Основание | Статус | Эксперимент | Kill | Success | Прогон |
|---|---|---|---|---|---|---|---|---|

Карточек пока нет — первые появятся после первого прогона `/flow lab`.
