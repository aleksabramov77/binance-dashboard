# Лаборатория: где живёт память `/flow lab`

Прогоны, журнал решений и бэклог гипотез лаборатории — **в приватном репозитории** `binance-dashboard-private`
(клон в игнорируемой папке `private/`, spec 0015): репозиторий публичный, а цифры, параметры удачных комбинаций и
гипотезы — «рецепты».

| Файл (в `private/lab/`) | Что | Кто пишет |
|---|---|---|
| `journal.md` | Записи прогонов, новые сверху: период, рынок, решения, что применено, гипотезы | оркестратор `/flow lab`, этап journal |
| `hypotheses.md` | Все карточки гипотез `H<n>` (pursue, revise, discard) со статусами и kill/success-критериями | оркестратор, этап journal |
| `<дата>-<NNNN>/report.md`, `report.json`, `trades.csv`, `skipped.csv` | Отчёт по сделкам эпохи, архив её сделок и отсечённых лимитом сигналов (`pnpm lab:report`) | скрипт (руками не править) |
| `<дата>-<NNNN>/review.md` | Разбор: подозрительное, решения keep/mirror/tune/pivot/kill, действия | агент `quant` |
| `<дата>-<NNNN>/ideas.md` | Карточки гипотез прогона, отклонённые идеи, выбор пользователя | агент `quant`; выбор — оркестратор |
| `<дата>-<NNNN>/apply.md` | Что реально переключили в БД («было → стало») | `pnpm lab:apply --out` |

Новые эксперименты — `private/experiments.json` + `pnpm lab:private --prod` (не `catalog.ts`). Процесс —
`.config/flows/lab.yaml`, метод — скилл `trading-lab`, форматы — его `references/outputs.md`. В публичный
репозиторий из прогона попадает только строка задачи в `docs/HISTORY.md`. Новый строительный блок ядра (тип входа,
выхода, фильтр) — обычной задачей `/flow feature`, без параметров удачных комбинаций.
