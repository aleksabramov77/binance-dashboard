# features/scan-market

Серверный слайс: сканер лидеров роста/падения и детектор торговых сетапов. Вызывается из
`app/api/signals/route.ts` (скан) и `app/api/signals/recheck/route.ts` (предпроверка перед сделкой).
Ходит только в публичное API Binance (+ справочник Demo Trading, чтобы знать, можно ли торговать символ).

## Публичный API
- `scanMarket()` — лидеры роста/падения + сетапы; результат кэшируется на `SCAN_CONFIG.cacheTtlMs`.
- `recheckSetup(setup)` — пересчёт сетапа по свежим свечам 1h/4h и цене без кэша.

## Устройство
- `config/rules.ts` — **все пороги**: ликвидность, `topN`, правила `REBOUND_LONG` / `OVERHEAT_SHORT`,
  риск-правила (SL от ATR, TP, R:R). Тюнинг правил — только здесь, без правки логики.
- `lib/computeIndicators.ts` — RSI, EMA, ATR по свечам (`shared/lib/indicators.ts`).
- `lib/detectSetup.ts` — чистая функция: mover + индикаторы → сетап с входом, SL, TP, R:R и
  списком проверок правил (`ruleChecks`) или `null`.
- `lib/evaluateRecheck.ts` — сравнение исходного сетапа со свежим пересчётом (актуален ли вход).
- `model/scanMarket.ts` — сеть: тикеры 24h, фильтр ликвидности, стейблкоины и плечевые токены
  (`UP/DOWN/BULL/BEAR`) отбрасываются, свечи по топу, детектор.

## Подводные камни
- Сетапы — гипотезы, точность правил не доказана (см. PRD §3.3 «Журнал»). Не выдавать их за сигналы
  «наверняка» в UI.
- Не расширять скан на сотни символов: лимиты веса Binance. Увеличение `topN` — осознанно.
- Шорт — только для символов, торгующихся на фьючерсах.
