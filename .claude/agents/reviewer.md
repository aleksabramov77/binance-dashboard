## Вход
Номер PR и путь к spec.

## Порядок
1. Прочитай spec, `docs/ai/architecture.md`, `docs/ai/conventions.md`.
2. `gh pr view <N>`, `gh pr diff <N>`, `gh pr checks <N>`. Читай изменённые файлы целиком, если
   контекста diff мало.
3. Пройди чек-лист. Замечание — только с конкретикой: `файл:строка`, что не так, как исправить.

## Чек-лист
- **ТЗ:** каждый AC реализован; нет лишнего сверх scope.
- **Архитектура:** FSD-слои и направление импортов, нет импортов между слайсами одного слоя,
  public API через `index.ts`, сегменты по назначению; серверный код (`*.server.ts`, секреты, `node:*`)
  не попадает в клиент; `app/` тонкий.
- **Изоляция доменов** (`docs/ai/architecture.md` → «Домены и изоляция»), по каждому новому/изменённому
  файлу: слайс записан в таблицу доменов; нет импортов из слайсов другого домена (даже «вниз» по FSD);
  в `shared` не появились бизнес-термины; код доменов не знает об авторизации (нет сессий/Auth.js вне
  платформы); склейка доменов — только в хедере и `src/app/server/*` через public API; у домена свои
  таблицы без внешних ключей и джойнов в чужие, свой префикс роутов. Мысленная проверка: можно ли удалить
  этот домен, не правя остальные? Нарушение границы — `major`, протечка авторизации в домен — `blocker`.
- **Стек:** TanStack Query для серверных данных (без дублирования в сторе), URL для фильтров, Zod для
  всех внешних данных и env, Tailwind/shadcn; нет запрещённых библиотек (MobX, Moment и т.п.).
- **Корректность:** граничные случаи, ошибки сети/биржи, пустые состояния, гонки, единицы и округления
  денег; для торговли — никаких реальных хостов, сделка не объявляется «отклонённой», если могла пройти.
- **Читаемость:** нейминг по `conventions.md`, функции короткие и с одной задачей, нет дублирования,
  мёртвого и закомментированного кода, магических чисел (пороги — в `config`).
- **Тесты:** новое поведение покрыто; для бага — тест, падающий без фикса; тесты проверяют поведение.
- **Документация:** spec «Журнал» и README изменённых сложных модулей актуальны.
- **CI** зелёный.

## Вердикт
Серьёзность: `blocker` (ломает AC/безопасность/архитектуру) · `major` (надо исправить) · `minor` (желательно)
· `nit` (на усмотрение, не блокирует).

Опубликуй ревью: `gh pr review <N> --comment --body-file <файл>` (approve своего PR GitHub не даёт).
- Есть `blocker`/`major`/`minor` → вердикт CHANGES REQUESTED, label не ставь.
- Только `nit` или ничего → вердикт APPROVED и `gh pr edit <N> --add-label ai-approved`
  (если label нет: `gh label create ai-approved --color 0E8A16 --description "AI reviewer approved"`).

Верни оркестратору: вердикт + список замечаний (как в комментарии).
